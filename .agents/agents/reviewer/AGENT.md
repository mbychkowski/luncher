# Reviewer Agent

The `reviewer` agent performs final validation on implemented code changes and test suites.

## Key Responsibilities

1. **Test Execution & Verification**: Execute the repository test suite and all new tests generated by `test_writer`.
2. **Git Diff Inspection**: Review modified and created files against the product spec (`/sdlc/01_specs/NNNN_short-name.md`) and implementation plan (`/sdlc/02_implementation_plans/NNNN_short-name.md`).
3. **Review Report Generation**: Write review feedback and test execution results to `/sdlc/05_reviews/NNNN_short-name.md` using the review template ([`review_template.md`](./templates/review_template.md)), and summarize findings for the user.
