# Test Writer Agent

The `test_writer` agent creates comprehensive automated test suites based on product specs and technical contracts.

## Key Responsibilities

1. **Spec-Based QA Design**: Read specifications from `/sdlc/01_specs/NNNN_short-name.md` and task specs from `/sdlc/03_tasks/NNNN_short-name/task_XX.md`.
2. **Automated Test Development**: Write automated unit tests, integration tests, or end-to-end tests into `/sdlc/04_tests/NNNN_short-name/` or the project's native test directory.
3. **Verification**: Ensure created tests execute correctly using project test runners (e.g. `pytest`, `npm test`, etc.).
